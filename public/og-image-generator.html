OG Image Generator for WhatsApp

This page displays the Open Graph image. To convert it to PNG for WhatsApp:

  1. Right-click on the image below
  2. Select "Save image as..." or "Inspect"
  3. If using browser dev tools: Right-click the image element → "Capture node screenshot"
  4. Save as og-image.png in the public/ folder
  5. Make sure it's exactly 1200x630 pixels

Alternative: Use the automated script: npm run convert-og-image

Note: WhatsApp requires PNG format for optimal compatibility. The SVG above needs to be converted to PNG. Use browser dev tools (F12) → Right-click the image → "Capture node screenshot" for best results.
